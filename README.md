## 🌟 Overview

**AttenMo** is an all-in-one digital attendance and academic tracking ecosystem designed specifically for university students, Class Representatives (CRs), and educational institutes. By combining real-time Cloud Firestore synchronization, automated timetable calculations, and a high-performance progressive web app (PWA) architecture, AttenMo eliminates manual attendance tracking hassles and empowers students with real-time academic analytics.

---

## ✨ Key Features & Capabilities

### 1. 📊 Student Attendance Tracker & Analytics
- **Subject-Wise Tracking:** Real-time logging of attended, missed, and total lectures per subject.
- **Safe Margin & Bunk Calculator:** Smart algorithm calculating how many lectures a student can safely skip (or must attend) to maintain target attendance thresholds (e.g., 75%).
- **Automated Timetable Sync:** Smart scheduled logs aligned with daily class timetables.

### 2. 👑 CR (Class Representative) Management Suite
- **Centralized Class Roster:** Manage student lists, subject assignments, and class schedules from a unified dashboard.
- **Bulk & Instant Marking:** Rapid attendance submission designed to save instructional time.
- **Export & Summary Reports:** Generate and share class-wide attendance reports with faculty or students seamlessly.

### 3. 🎓 Instant Student Portal
- **Dedicated Light Portal (`track.html`):** Fast-loading student interface for instant access to attendance status, subject performance, and personal records without unnecessary navigation steps.

### 4. 📱 Modern Architecture & UX
- **Glassmorphism UI:** Premium dark/light themes tailored for modern high-refresh-rate displays.
- **PWA & Native Mobile Ready:** Seamless offline support, push notification architecture, and Capacitor-powered Android integration.
- **Real-Time Cloud Synchronization:** Powered by Firebase Authentication and Firestore for instant multi-device state consistency.
